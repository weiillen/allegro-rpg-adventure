# Asset and License Notes

The original archive contains PNG sprites, a tile atlas, UI graphics, MP3/OGG/WAV audio files, and `Minecraft.ttf`. It does not contain a complete attribution list or license information for those assets.

The files are preserved to keep the submitted project reproducible. Before making the repository public, confirm that each asset can legally be redistributed and add the correct author, source, and license information.

The following points deserve particular attention:

- `Minecraft.ttf` may be governed by a separate font license.
- The same sound is often included in MP3, OGG, and WAV form, although the source currently loads the MP3 variants.
- Image filenames alone are not sufficient evidence of authorship or redistribution permission.
- No license has been added to the repository because licensing the code would not automatically license third-party art, audio, fonts, or course-framework components.

The generated `docs/asset-overview.png` is only a collage of the preserved files and does not establish ownership of the underlying assets.
